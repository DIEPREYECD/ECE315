What is an Embedded System?
An embedded system is a special-purpose computer system designed to perform a dedicated function or a specific set of tasks, often within a larger mechanical or electrical system.
· ChatGPT
An embedded system is a computer system that is used to monitor and control a product or engineering system. An embedded system often has only a simplified and/or an application-specific user interface. A conventional PC or tablet user interface is usually absent in an embedded system.

Why Embed a Processor?
· Increasingly inexpensive, so why not?
· RP2040, a Cortex-M0+ processor that runs at 133 MHz and is 32-bit is $CA1 · Other processors can be as low as a few pennies in quantity
· Distributes processing
· Reduced single-point failure risk · Greater flexibility ­ e.g., can change one small part of a system without
having to re-program the main part
· High-speed signal processing for better sensing, can compensate for sensor inaccuracies, shifts due to environment, aging, etc.
· Can improve function via upgrades (not the pennies processors!)

Real-Time Embedded Systems

· Primarily focused on real-time embedded systems in this course
· Real-time system is fast enough to react to changes in its environment to control something correctly, efficiently, and safely.
· A hard real-time embedded system;
· Violations of real-time constraints are unacceptable · Constraint violations could cause injury or death, equipment damage, loss of
material, and/or serious financial loss
· A soft real-time embedded system;
· Occasional violations of the real-time undesirable, but can be tolerated · E.g., a vending machine or an Automated Teller Machine (ATM) can tolerate
small delays with only minimal occasional inconvenience to human users.

Performance Measures

· Algorithm correctness: Do all possible inputs produce the desired system state changes and outputs?
· Response time: Does the system respond fast enough to input/external changes?
· Predictable or deterministic response time: Is the response time sufficiently predictable (that is, have a small variance) as well as being acceptably fast?
· Resource efficiency: Was the consumption of power, natural gas, water, other chemicals, communication bandwidth, etc. minimized when accomplishing the work?

Adapted from ECE 315 W2025 by Dr. Bruce Cockburn

Early Embedded Systems

· D-17B (D17B) computer was used in the Minuteman I NS-1OQ missile guidance system (1962)
· 62 pounds (28 kg), · 1,521 transistors, 6,282 diodes, 1,116 capacitors, and 5094 resistors
· Mounted on 75 double copper-clad, engraved, gold-plated, glass fiber laminate circuit boards
· The high degree of reliability and ruggedness of the computer were driven by the strict requirements of the weapons system.

Amdahl power requirements
· The Amdahl 470 processors are air cooled and require a minimum of 12.5 tons of air conditioning and 4890 cubic feet of air per minute. Minimum BTU output for a 470 processor is 79,000 BTUs per hour. Figures are generally higher depending on the processor model and amount of memory installed. Power must be available to the Amdahl 470 power distribution unit from two sources, 415 and 60 Hz. Both sources must be four wire and three phase at 208 volts.
· 79,000 BTU is about 23 kWatt (!)

Embedded Applications ­ Supervisory Control and Data Acquisition Systems (SCADA)

· SCADA stands for Supervisory Control and Data Acquisition.
· It is a computer-based system used to monitor and control industrial processes across large-scale or distributed environments such as factories, power plants, water treatment facilities, and transportation networks.
· A SCADA system is an industrial control system (ICS) that gathers real-time data from remote sensors and equipment, processes that data, and enables supervisory control -- allowing operators to monitor, analyze, and manage operations from a central location.

SCADA ­ Core Componets
Sensors and Actuators: · Measure process variables (temperature, pressure, flow, voltage) and perform control actions
(open/close valves, start/stop motors). Increasingly have embedded processors Remote Terminal Units (RTUs) or Programmable Logic Controllers (PLCs): · Embedded processor unit that interfaces with sensors and actuators in the field; collect data and
execute control commands. Communication Network: · Connects RTUs/PLCs with the central control system, often using industrial communication
protocols (Modbus, DNP3, OPC, Ethernet/IP). SCADA Master Station / HMI (Human­Machine Interface): · Central servers and graphical user interfaces that visualize data, log events, and allow operators
to issue control commands.

Embedded Challenges
· (Almost) Everything is constrained
· Might have only kB of RAM, not GB · Might have only MB of FLASH, not TB · Processor clock of MHz, not GHz · No dedicated floating-point processing · Limited operating system, if any
· Do have
· Lots of I/O · Smart I/O -- peripheral devices do things for you, e.g., DMA, SPI, I2C, ADC · Low cost
