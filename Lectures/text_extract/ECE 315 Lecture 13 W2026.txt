Learning Objectives
• Define “Hardware Abstraction Layer (HAL)” and why it’s needed
   • Understand the concept of a HAL as a software layer that separates application‐level code
     from hardware-specific details
• Explain why a HAL is needed
   • Recognize how a HAL improves portability, maintainability, and code clarity by hiding
     processor-specific registers and configurations behind a consistent API
• Recognize and understand the structure and layered architecture of a HAL
   • Application layer
   • HAL (GPIO, UART, SPI/I2C, timers, ADC, DMA, PIO)
   • MCU port (register-level implementation)
   • BSP (board-specific pin maps, clocks, power setup)
   • Physical MCU hardware
   • And how each layer has clear responsibilities.

FreeRTOS UART Support

• Knowing how to use an UART is very useful in embedded
  programming
  • Not only for moving data between processors and peripherals
  • Also for debugging (simple command-line interface, debug “printf’s”, etc.)
• Up to the programmer to provide specialized functions to access the
  specific features of the target architecture (Zynq, RP2040, …)
• FreeRTOS is, by definition, portable across processor architectures
  • In ECE 315 it’s used on the Zynq and RP2040 (Pico)
• For each processor, a kind of adaptation layer of software is needed

static inline void pad_cfg(uint8_t pin, const gpio_cfg_t *cfg) {            mcu/rp2040/gpio_rp2040.c
    // PADS_BANK0: pullups/pulldowns, drive, schmitt, slew
    volatile padsbank0_hw_t *P = PADS_BANK0;
    uint32_t v = 0;
    if (cfg->pull == GPIO_PULL_UP)    v |= PADS_BANK0_GPIO_PUE_BITS;
    if (cfg->pull == GPIO_PULL_DOWN) v |= PADS_BANK0_GPIO_PDE_BITS;
    if (cfg->slew_fast)               v |= PADS_BANK0_GPIO_SLEWFAST_BITS;
    if (cfg->schmitt)                 v |= PADS_BANK0_GPIO_SCHMITT_BITS;
    // drive_mA → DRV field (00=2mA,01=4mA,10=8mA,11=12mA)
    v |= ((cfg->drive_mA >= 12) ? 3 : (cfg->drive_mA >= 8) ? 2 : (cfg->drive_mA >= 4) ? 1 : 0)
        << PADS_BANK0_GPIO_DRV_LSB;
    P->io[pin] = v;
}

    uart_hw_t *u = U(inst);
