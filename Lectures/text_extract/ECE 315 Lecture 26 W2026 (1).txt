 Video Graphics Array (VGA)

 • Refers to both a de facto standard and hardware computer display
    • These days always uses 15-pin D-subminiature connector and 640x480 pixel
      resolution
 • Very quickly and widely adopted, still in use
 • Various extensions to higher resolutions, e.g., up to 2048x1536
 • Comprises 3 main binary TTL (5V) signals
    • Horizontal sync
    • Vertical sync
    • RGB levels

 RP2040 (Pico) Implementation
• Three PIO state machines
  (synchronized with one another
  via interrupts) drive a VGA screen.
• The pixel data to draw on the
  screen is communicated to the PIO
  state machines via DMA
• Pixel data is stored in a global
  character array
• Application code need only update
  the array

• The idea is to output bits on a GPIO pin at a constant rate so that the
  resulting signal is a form of pulse-width modulation (PWM)
• Using a parallel in, serial out (POSI) shift register, this is be easily
  accomplished

Use the RP2040 PIO Shift Register
• We can use the PIO output shift
  register (OSR)
• OSR connected to a GPIO
• OSR starts with 32-bit PWM pattern
• Bits are shifted out to the GPIO that
  is attached to an LED to turn it on a
  specific percentage of time
• Every 32 PIO clock cycles fill the TX
  FIFO, which is then copied into the SR
  when the register is empty

                                                18
Use the RP2040 PIO Shift Register
• Set the PIO clock to be 10 system
  clock cycles
• Use 32 bits, so 32 PWM levels
• Outputting the 32 bits of one level
  will take

 32*10/fclk = 320/125e6 =
 2.56µs
• Going through all 32 levels will take
  32*2.56 = 81.92µs

Use the RP2040 PIO Shift Register
• We want the 32 levels to take 2
  seconds in total so the LED changing
  can be seen (it’s not too fast)
• Thus, we need to repeat each level

   2s/81.92µs ~= 24414 times

     static inline void pio_serialiser_program_init(PIO pio, uint sm, uint offset, uint data_pin, float clk_div) {

         pio_sm_set_consecutive_pindirs(pio, sm, data_pin, 1, true);

         sm_config_set_fifo_join(&c, PIO_FIFO_JOIN_TX);
         sm_config_set_clkdiv(&c, clk_div);
         sm_config_set_out_shift(&c, true, true, 32);
         pio_sm_init(pio, sm, offset, &c);
         pio_sm_set_enabled(pio, sm, true);
     }
     %}

Summary

• Showed how RP2040 PIO can be used to generate complex hardware
  waveforms, barely using the CPU
  • In the example, the CPU was used mostly to compute the Mandelbrot set
• After review of VGA signals, showed how one PIO state machine (SM)
  is used to generate H Sync, one generates V Sync, the the third SM
  clocks out the RGB signals
• A second example using only DMA and PIO, no CPU, to cycle an LED
  through 32 PWM levels
  • Used the clock divider to slow the PIO and repeated DMA transfers to make
    the PWM ramping “human speed”
