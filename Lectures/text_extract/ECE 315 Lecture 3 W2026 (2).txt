Definitions

• A computer is a highly complex synchronous finite state machine.
• Bus = a logical grouping of wires that carry related signals; e.g., an 8-
  bit data bus has a width of 8 bits, and thus moves 1 byte at a time.
   • Data bus — moves information between system components, usually one word wide
   • Address bus — for CPU to indicate which memory or I/O location is being accessed
• Control signals — allow CPU to communicate system state to other
  components; e.g., reading vs. writing data
• Clocks — One or more frequency-stable square-wave clock signals
  are required to synchronise and initiate events.

Information in a Computer

• Binary digits can be used to represent individual values or characters
• Groups of them can represent numbers (floating point, signed or
  unsigned integers, complex numbers, etc.) or character strings
  (words, sentences)
• More complex combinations can represent abstract entities, like
  documents, spreadsheets, database entries, etc,
• Information is stored in memory or transmitted via buses or I/O
  channels.

Representing State and Instructions

• The computer, and in particular the CPU and specific logic circuits,
  maintains state
• Inputs to the state machine are considered to be “instructions” that
  together comprise a computer “program”
  • You are well-aware of Python and now C programs and programming
  • Languages like them are a high-level abstraction of the state machine inputs
    that cause changes in state
  • A change in state or a series of changes results in some desired action, such
    as saving data to memory (RAM) or a signal sent to an I/O device

Programming Languages
• High-level programming languages like C, Python, Java are used to
  provide a high-level abstraction for the low-level machine instructions
• Assembly language is the lowest-level abstraction for machine
  instructions
  • Provides a one-to-one mapping
• A compiler and linker translate one or more program files into low-
  level machine instructions and link them with others that are pre-
  existing and a part of libraries
• The resulting programs are stored in program memory
  • Often this is non-volatile storage like FLASH

Specifying Numerical Values in Source Code
• We will focus on the C language as it is less abstracted from the true
  “machine” code that defines the instructions the computer interprets
• When we want to specify numerical values, we use one of several
  bases – decimal, binary, octal, or hexadecimal
   Example: To specify the numeric value ten, we can write this as:
   • 10— decimal by default
   • 0x0A — the 0x prefix denotes a hexadecimal value follows
   • 0b1010 — the 0b prefix denotes a binary value follows
   • 012 — a leading zero on an integer denotes octal

Advanced RISC Machines – ARM

• A very popular, common computer architecture was developed by
  companies that eventually became ARM starting in the early 80s
• It’s no perfectly correct to say “computer architecture” because ARM
  licenses a family of Reduced Instruction Set Computer (RISC)
  instruction set architectures
  • ARM specifies the instructions and companies build hardware to execute
    them
• Over 200 billion ARM-based computers sold so far (at least!)

Zybo Features
ZYNQ Processor
• 667MHz dual-core Cortex-A9 processor
• DDR3L memory controller with 8 DMA channels and 4 High Performance AXI3 Slave ports
• High-bandwidth peripheral controllers: 1G Ethernet, USB 2.0, SDIO
• Low-bandwidth peripheral controller: SPI, UART, CAN, I2C
• Programmable logic equivalent to Artix-7 FPGA
Memory
• 1 GB DDR3L with 32-bit bus @ 533 MHz (1066 MHz)
• 16 MB Quad-SPI Flash with factory programmed 128-bit random
  number and 48-bit globally unique EUI-48/64™ compatible identifier
• microSD slot
