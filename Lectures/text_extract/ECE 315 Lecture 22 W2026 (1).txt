RP2040 Memory Map – AHB-Lite Peripherals

• The Advanced High-Performance Bus is based on a Direct Memory
  Access (DMA) controller
• It coordinates and performs bulk data transfers on the processor’s
  behalf, leaving it to do other things
• The throughput using the DMA is much faster than having the
  processor move data
• At base address of 0x50000000 various DMA registers are mapped
  • The programmer writes or reads data at offsets corresponding to specific
    functional registers

Summary

• Microprocessors use memory-mapped I/O to access peripherals via
  normal memory addresses
  • For example, for the Cortex-M0+ (RP2040) peripherals accessed through APB
    & AHB buses
  • RP2040 memory map includes ROM, Flash (XIP), SRAM, APB peripherals,
    AHB-Lite peripherals, and GPIO registers
  • Examples of mapped peripherals: CLOCKS, RESETS, GPIO, UART, ADC, TIMER,
    PWM, DMA
• SPI example shows direct register manipulation for peripheral
  configuration and data transfer
