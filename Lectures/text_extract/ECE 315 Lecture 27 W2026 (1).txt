Using DMA to capture real world data
• It is very common to interface computers, microcontrollers to the real
  world
  • The Internet of Things (IoT), such as thermostats, cameras, switches, …
  • Automotive systems,
  • Heating, ventilation, and air-conditioning (HVAC)
  • Building electrical and power systems
  • Biomedical systems
  • Human-interface systems
  • Audio entertainment systems
• DMA supports efficient data and signal gathering without CPU
  loading

Summary
• Many embedded systems must interface with analogue real-world signals (IoT,
  automotive, HVAC, biomedical, audio).
• DMA enables high-rate, low-overhead data acquisition by moving ADC samples
  directly into memory without CPU involvement.
• In digitally-controlled analogue systems, ADCs, DMA, DACS, memory buffers, and
  CPUs can form effective feedback control systems.
• The RP2040 ADC supports multi-channel, round-robin sampling with a shared
  FIFO, requiring sample de-interleaving.
• Ring buffers and DMA interrupt handlers enable continuous sampling while the
  CPU performs processing asynchronously.
• Because DMA operates independently of the CPU, careful design is required to
  maintain data consistency and avoid timing issues.
